# Spotify-Data-Analysis-Project
To analyze Spotify top songs datset and find patterns in music trends
# Dataset
Contains song name,artist,popularity and genre
# Tools Used
-Python
-Pandas
-Matplotlib
-Seaborn
# Steps
-Data cleaning
-Exploratory Data Analysis(EDA)
-Visualization
# Insights
-Few artists dominate
-Popular genres stand out
-Popularity varies across songs
# Conclusion
The project reveals trends in music and listner preferences
